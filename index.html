GTA 6 Hub analytics

A private tool for the GTA 6 Hub YouTube channels. It reads each channel's YouTube Analytics, like views, watch time and audience retention, so the person who runs the channels can see how every video does and plan the next ones

It uses YouTube API Services with read-only access, so it can't upload, change or delete anything. It isn't a public service: only the owner of the GTA 6 Hub channels signs in to it
